# 🌟 Shine Star - Employee Management System

A full-stack Employee Management System built using React, Spring Boot, and MySQL.

## 🚀 Live Demo

👉 https://shine-star-employee-management-syst.vercel.app

## ✨ Features

- 🔐 Admin Login
- 📊 Dashboard
- 👨‍💼 Add Employee
- 📋 Employee List
- 🔍 Search Employees
- 👤 Employee Details
- ✏️ Edit Employee
- 🗑️ Delete Employee
- 📅 Attendance Management
- 📈 Attendance Summary
- ⚙️ Settings
- 🔒 Protected Routes
- 🌐 REST API Integration

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- React Router
- Axios
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST API

### Database
- MySQL

### Deployment
- Vercel – Frontend
- Railway – Backend & Database
